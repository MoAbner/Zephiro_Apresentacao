Zephiro é uma solução de acessibilidade para pessoas com deficiência visual que usa câmera, voz e áudio dos Meta AI Glasses para descrever o ambiente em tempo real, via agente de IA rodando no smartphone.

O Problema

Navegar o mundo sem visão exige informação constante

Pessoas com deficiência visual dependem de bengalas, cães-guia e auxiliares humanos para tarefas que videntes realizam automaticamente: reconhecer quem está na sala, ler o cardápio, atravessar uma rua movimentada ou identificar um produto na prateleira. Soluções existentes são isoladas, caras ou exigem hardware dedicado inacessível. Os Meta AI Glasses mudam essa equação: câmera, microfone e alto-falante já estão integrados em um óculos comum.

A Solução

Câmera vê. IA entende. Óculos falam.

Os óculos capturam o ambiente pela câmera e recebem comandos pelo microfone. O smartphone Android processa tudo localmente com o agente de IA e devolve a resposta como áudio direto nos alto-falantes dos óculos, sem display, sem toque, sem interrupção.

Módulos Técnicos

Funcionalidades que transformam a experiência

Cada módulo foi projetado para rodar com baixa latência no smartphone ou até no óculos se possível, usando os canais nativos dos óculos como entrada e saída. Como temos muitos módulos, a ideia vai ser produzir em etapas para que ao concluir um dos módulos de forma funcional já possamos entregar uma experiência completa ao usuário, mesmo que parcial.

📷
Detecção de objetos em tempo real
A câmera dos óculos transmite frames continuamente para o app via Meta Wearables Device Access Toolkit. Um modelo de visão computacional leve identifica pessoas, veículos, obstáculos e objetos no campo visual, classificando-os por proximidade e relevância para o usuário.
YOLOv8n Camera DAT API ONNX Runtime Android
🎤
Comando de voz com wake word "Zephiro"
O microfone dos óculos escuta continuamente. Ao detectar a palavra "Zephiro", o agente acorda e interpreta o comando seguinte: "descreva o ambiente", "tem alguém perto de mim?", "o que está na minha frente?". O reconhecimento roda offline diretamente no smartphone.
Mic DAT API ASR offline Wake word engine NLU local
🔊
Alertas e respostas por áudio
Toda saída ao usuário é entregue via alto-falante dos óculos — o único canal de saída disponível. Alertas proativos ("pessoa se aproximando pela esquerda") combinam com respostas sob demanda a comandos de voz. TTS leve e natural, sem latência perceptível.
Speaker DAT API TTS Android Fila de prioridade de áudio
🤖
Agente de IA contextual
Um agente leve coordena detecção visual, reconhecimento de voz e síntese de resposta — idealizado para rodar diretamente nos óculos, sem depender do smartphone. Onde o hardware dos óculos não suportar o modelo completo, o processamento cai para o smartphone pareado via Bluetooth, mantendo a experiência idêntica para o usuário. Sem internet, sem latência de rede.
On-device nos óculos Fallback Android Gemini Nano / LLM embarcado
🗺️
Memória de trajetos — Zephiro Guide
O usuário salva caminhos recorrentes — de casa ao trabalho, à farmácia, à escola — e os recupera por voz: "Zephiro, me guia para o mercado". O sistema combina GPS do smartphone com pontos de referência auditivos gravados pelo próprio usuário ("vire à direita após o portão") para criar uma navegação contextual e personalizada, sem depender de visão ou de conectividade constante.
GPS + sensor de movimento Waypoints por voz Reprodução offline Armazenamento local
📄
Leitura de documentos e textos — Zephiro Read
A câmera dos óculos captura qualquer texto no campo visual — cardápios, placas, bulas, documentos, telas — e o Zephiro lê em voz alta em segundos. Funciona com um simples comando de voz: "Zephiro, leia isso". OCR leve roda on-device, sem enviar imagens para a nuvem, garantindo privacidade mesmo com documentos sensíveis.
OCR on-device Camera DAT API TTS neural Ativação por voz
Arquitetura

IA nos óculos, smartphone como suporte

A arquitetura ideal do Zephiro roda o agente de IA diretamente nos Meta AI Glasses — câmera, processamento e resposta em áudio sem passar pelo smartphone. Onde o hardware dos óculos não suportar o modelo completo, o Meta Wearables Device Access Toolkit conecta os óculos ao app Android via Bluetooth, que assume o processamento. Para o usuário, a experiência é a mesma nos dois cenários.

Aderência ao Edital

Checkpoints técnicos obrigatórios

O Zephiro foi desenhado desde a concepção para cobrir todos os cinco checkpoints do programa.

✓
Uso de Inteligência Artificial
Detecção de objetos com YOLOv8n, ASR offline e agente de linguagem natural rodando localmente no smartphone durante o hackathon — comprovável em tempo real.
✓
Câmera e microfone como canal principal
100% das entradas do sistema passam pela câmera (visão) e microfone (comando de voz) dos óculos via Meta Wearables Device Access Toolkit. Nenhuma interação é feita pelo smartphone.
✓
Output por áudio
Toda resposta ao usuário é entregue pelos alto-falantes dos óculos. Não há display, toque ou notificação visual — o áudio é o único e exclusivo canal de saída, adequado para usuários com deficiência visual.
✓
Privacidade e dados
Todo processamento é local — câmera, ASR, detecção e síntese. Nenhum frame ou áudio é enviado a servidores externos. Sem armazenamento persistente de dados sensoriais.
✓
Eficiência de bateria
Pipeline com detecção a cada N frames configurável, ASR ativado apenas após wake word e modelo de IA quantizado reduzem significativamente o consumo. Modo silencioso desativa o pipeline de detecção quando solicitado por voz.
